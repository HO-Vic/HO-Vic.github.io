1. GitHub 토큰

이 페이지는 서버 없이 동작합니다. 발행 버튼을 누르면 내 브라우저에서 직접 GitHub에 커밋합니다. 그래서 쓰기 권한이 있는 토큰이 필요합니다.

토큰 발급하기 → Repository access는 HO-Vic.github.io 하나만, Permissions는 Contents: Read and write만 주세요. 만료일도 짧게 잡는 게 좋습니다.

⚠ 저장하면 이 브라우저를 쓰는 사람은 누구나 발행할 수 있습니다. 공용·공유 PC에서는 저장하지 마세요. 토큰이 유출된 것 같으면 GitHub 설정에서 바로 revoke하면 됩니다.
